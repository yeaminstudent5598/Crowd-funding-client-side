Welcome to Gadget Heaven, a platform to explore and manage the latest gadgets. Dive into exclusive products and enjoy a seamless shopping experience!

## React Concepts Used
This project implements several fundamental React concepts:
- *React Hooks*: `useState`, `useEffect`, `useContext` for state and lifecycle management.
- *React Router*: Navigation between different views and dynamic routes.
- *Component Structure*: Modular approach for reusable components.
- *Context API*: State management for sharing data across components.
- *PropTypes*: Type-checking to ensure reliability and maintainability.

## Data Management
- *Context API*: Used for handling global state such as the wishlist and cart items.
- *Local Storage*: Optionally used for data persistence.

## Key Features
1. *Dynamic Dashboard*: View and manage products in the cart and wishlist.
2. *Product Sorting*: Sort items in the cart by price for quick decision-making.
3. *Wishlist Management*: Easily add or remove items from your wishlist for future reference.
4. *Toast Notifications*: Real-time feedback when items are added to the cart or wishlist.
5. *Responsive Design*: Optimized for various screen sizes for an enjoyable experience on any device.  

## Toast Notifications
- *Adding Item to Cart*: Displays a success message when an item is added to the cart.
- *Adding Item to Wishlist*: Shows a different success message for wishlist additions.
